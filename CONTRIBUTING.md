# Как работаем

Команда из 5 человек, хакатон 48 часов. Чтобы не терять чужой код, держимся коротких правил.

## Ветки

Имя ветки: `tXX-кратко`, например `t11-qubo`.

Всегда начинай от актуальной `main`:

```bash
git checkout main
git pull
git checkout -b t11-qubo
```

## Общие модули

Файлы `qubo.py`, `qaoa.py`, `scene.py`, `classical.py` — общие. Перед тем как писать в них, договоритесь, кто что берёт. Не правьте чужой кусок «заодно».

## «Продолжить файл»

Это значит: добавить свою функцию в актуальную версию файла. Не переписывать чужой код, не подменять файл целиком, не рефакторить соседние функции без договорённости.

## Merge

В `main` только через Pull Request. Прямой push в `main` не делаем.
